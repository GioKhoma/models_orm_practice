
# 🧱 DJANGO MODELS & ORM PRACTICE

## 📝 პრაქტიკული დავალება: Django მოდელებისა და ურთიერთობების შექმნა

ამ დავალების მიზანია Django-ს **მოდელების, ველებისა და ურთიერთობების** პრაქტიკაში გამოყენება.

თქვენ უნდა შექმნათ პატარა სისტემა, სადაც მოდელები ერთმანეთთან ლოგიკურად იქნება დაკავშირებული.

---

## 🎓 დავალება: შექმენით საკუთარი სისტემა

### ძირითადი მოთხოვნები

✅ შექმენით **მინიმუმ 6 მოდელი**.

✅ გამოიყენეთ სამივე ტიპის ურთიერთობა:

- `OneToOneField`
- `ForeignKey`
- `ManyToManyField`

✅ თითოეულ მოდელს უნდა ჰქონდეს მინიმუმ **3 ველი** (ურთიერთობის ველების ჩათვლით).

✅ მინიმუმ 2 მოდელში გამოიყენეთ `DateTimeField` ან `DateField`.

✅ მინიმუმ ერთ მოდელში გამოიყენეთ `BooleanField`.

✅ ყველა მოდელში შექმენით `__str__()` მეთოდი, რომელიც ობიექტის შესახებ გასაგებ ინფორმაციას დააბრუნებს.

✅ მოდელები ერთმანეთთან ლოგიკურად უნდა იყოს დაკავშირებული.

## 📌 აირჩიეთ მხოლოდ ერთი სისტემა

ქვემოთ მოცემული ვარიანტებიდან აირჩიეთ **მხოლოდ ერთი** და შექმენით შესაბამისი მოდელები.

### 🎬 ვარიანტი 1 — ფილმების პლატფორმა

შექმენით სისტემა, სადაც შესაძლებელი იქნება ფილმების, მსახიობების, რეჟისორების, ჟანრებისა და შეფასებების შენახვა.

ურთიერთობების მაგალითები:

- ფილმი ↔ რეიტინგი — `OneToOneField`
- რეჟისორი → ფილმები — `ForeignKey`
- ფილმები ↔ მსახიობები — `ManyToManyField`

### 🏢 ვარიანტი 2 — კომპანიის მართვის სისტემა

შექმენით სისტემა, რომელიც შეინახავს ინფორმაციას კომპანიების, თანამშრომლების, დეპარტამენტების, პროექტებისა და სამუშაო პოზიციების შესახებ.

ურთიერთობების მაგალითები:

- თანამშრომელი ↔ სამუშაო პროფილი — `OneToOneField`
- დეპარტამენტი → თანამშრომლები — `ForeignKey`
- პროექტები ↔ თანამშრომლები — `ManyToManyField`

### 📚 ვარიანტი 3 — ბიბლიოთეკის სისტემა

შექმენით სისტემა, რომელიც შეინახავს ინფორმაციას წიგნების, ავტორების, კატეგორიების, მკითხველებისა და წიგნების გაცემის შესახებ.

ურთიერთობების მაგალითები:

- წიგნი ↔ ISBN ინფორმაცია — `OneToOneField`
- კატეგორია → წიგნები — `ForeignKey`
- წიგნები ↔ ავტორები — `ManyToManyField`

### 🎓 ვარიანტი 4 — უნივერსიტეტის სისტემა

შექმენით სისტემა სტუდენტების, ლექტორების, საგნების, ფაკულტეტებისა და სასწავლო ჯგუფების სამართავად.

ურთიერთობების მაგალითები:

- სტუდენტი ↔ სტუდენტის პროფილი — `OneToOneField`
- ფაკულტეტი → სტუდენტები — `ForeignKey`
- სტუდენტები ↔ საგნები — `ManyToManyField`

**შენიშვნა:** ჩამოთვლილი მოდელები და ურთიერთობები მაგალითებია. შეგიძლიათ თავად მოიფიქროთ დამატებითი მოდელები და გადაწყვიტოთ მათი ერთმანეთთან დაკავშირების ლოგიკა.

## 🚀 შემდეგი ნაბიჯები

მოდელების შექმნის შემდეგ შეასრულეთ შემდეგი მოქმედებები:

1. გაუშვით `python manage.py makemigrations`.
2. გაუშვით `python manage.py migrate`.
3. შექმენით სუპერუზერი `python manage.py createsuperuser`.
4. დაარეგისტრირეთ ყველა მოდელი `admin.py` ფაილში.
5. დაამატეთ ობიექტები admin პანელიდან.
6. შეამოწმეთ, რომ მოდელებს შორის ურთიერთობები სწორად მუშაობს.
